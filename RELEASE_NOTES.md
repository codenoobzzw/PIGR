# PIGR KDD 2026 Artifact Release

Initial artifact release for the KDD 2026 paper "Beyond Structure-Driven Tuning: Cost-Aligned Graph Optimization for Approximate Nearest Neighbor Search".

This release includes source code, build instructions, dataset preparation notes, and scripts/documentation for running sanity checks and paper-style experiments for PIGR on graph-based approximate nearest neighbor search indexes.

Known notes:

- Large datasets and generated indexes are not included.
- ACM paper DOI: 10.1145/3770855.3817671.
- Zenodo DOI will be generated after this GitHub release is archived.
